# -bigmen-campagne
**OYE BA VACANCES** est la nouvelle campagne de BIG MEN qui célèbre la fin de l'année scolaire et le début des vacances. À travers une égérie, des contenus tendance et le lancement de 6 nouveaux menus, BIG MEN devient le rendez-vous incontournable pour célébrer les examens terminés et profiter entre amis.
